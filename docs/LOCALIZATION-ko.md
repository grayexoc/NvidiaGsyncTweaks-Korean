# 한국어화 변경 내역

## 변경한 코드
- \`UI/MainView.cs\`: GPU 검색/상태, 적용/복원 대화상자, 관리자 권한 안내, 성공/오류 메시지, 하단 작업 표시줄
- \`UI/LfcPage.cs\`: LFC 설명, 모드 선택, 미리보기, 주사율별 표, 사용자 지정 고정성 설명
- \`UI/BackupsPage.cs\`: 백업 목록, 백업 폴더 열기, 복원 안내 및 버튼
- \`UI/TweakRows.cs\`: 켜짐/꺼짐, 초기화, 변경됨/사용자 지정, 기본값 표시, 실험적/주의 배지
- \`UI/Ui.cs\`: 위험도 배지와 관리자 권한 안내
- \`Model/Catalog.cs\`: 각 설정의 제목, 설명, 옵션 및 참고 문구

## 변경하지 않은 부분
- 레지스트리 값 이름 및 값
- 기본값, 범위, 단위의 수치
- NVAPI 및 Windows API 호출
- GPU/디스플레이 탐색과 드라이버 재시작 로직
- 설정 계산 및 LFC 모델
- 테스트 코드와 CI 워크플로

## 검증 상태
이 실행 환경에는 .NET SDK 및 Windows 빌드 도구가 없어 컴파일, 테스트 실행, Windows UI 렌더링 검증을 수행하지 못했습니다. 번역은 C# 문자열 리터럴만 대상으로 적용했으며, 빌드 및 실제 실행 검증은 Windows에서 진행해야 합니다.
