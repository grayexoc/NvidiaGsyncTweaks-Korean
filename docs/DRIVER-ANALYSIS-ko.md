# NVIDIA 드라이버 VRR 내부 설정 — 한국어 안내

이 문서는 원본 \`DRIVER-ANALYSIS.md\`의 내용을 한국어로 요약한 참고 자료입니다. 원본 분석 대상은 NVIDIA 드라이버 621.12(\`nvlddmkm.sys\` 32.0.16.2112)입니다. 여기에 기록된 오프셋, 기본값 및 효과는 다른 드라이버 버전에서 달라질 수 있습니다.

## 설정 읽기 및 적용 시점

드라이버는 어댑터별 드라이버 레지스트리 키에서 설정을 읽습니다. 값이 없으면 드라이버 내부 테이블의 기본값을 사용합니다. 설정은 어댑터 시작 시 읽히므로 레지스트리 변경 후 디스플레이 드라이버를 다시 시작하거나 Windows를 재부팅해야 적용됩니다.

일반적인 키 형식:

\`HKLM\SYSTEM\CurrentControlSet\Control\Class\{4d36e968-e325-11ce-bfc1-08002be10318}\000N\`

\`0000\`이 항상 올바른 키인 것은 아닙니다. 여러 GPU, iGPU 또는 드라이버 재설치에 따라 번호가 달라질 수 있습니다. 앱은 NVAPI의 GPU/디스플레이 식별 정보와 PnP 어댑터의 PCI 버스·슬롯 및 드라이버 버전을 대조해 대상 키를 찾습니다.

## \`vrrFrameSplitBehavior\` — LFC 배수 선택

기본값은 \`0x80000055\`입니다. 드라이버는 프레임 시간 \`T\`에 대해 1배, 2배, 3배 등의 후보를 검사하고 각 후보가 모니터의 VRR 범위에 들어오는지 판단합니다.

- 기본 선택 방식은 VRR 범위 중앙에 더 가까운 배수를 선택합니다.
- 비트 16(\`0x10000\`)을 설정하면 조건에 맞는 가장 낮은 배수를 선택합니다. 커뮤니티 수정값 \`0x80010055\`가 이 방식을 사용합니다.
- 비트 0~7은 현재 배수를 유지하려는 고정성 값입니다. 기본 \`0x55\`(85)는 현재 배수에 15% 선택 보너스를 줍니다.
- 비트 17(\`0x20000\`)은 고정성을 비활성화합니다.
- 분석된 코드에서 비트 31, 8~15, 18~30은 읽히지 않습니다.

이 도구의 **최저 배수** 옵션은 프레임 속도가 VRR 최저 주사율 아래로 떨어질 때까지 1배를 유지하도록 하는 선택입니다. LFC를 끄는 기능은 아닙니다.

## 주요 VRR 값

| 레지스트리 값 | 원본 분석의 기본값 | 의미 |
|---|---:|---|
| \`vrrFrameSplitBehavior\` | \`0x80000055\` | LFC 배수 선택 |
| \`enableVrrFrameSmoothing\` | \`3\` | 값이 정확히 3일 때 프레임 스무딩 활성화 |
| \`vrrDeflickerMaxUs\` | \`3000\` | 한 프레임에 추가할 지연 상한(µs). 0은 스무딩 해제 |
| \`vrrMonAdj\` | \`50\` | 측정된 긴/짧은 프레임 불균형의 프레임별 보정 비율(%) |
| \`vrrDeflickerMaxPulsar\` | \`60\` | Pulsar로 분류된 패널의 추가 지연 제한 |
| \`vrrDecayCoefficient\` | \`30\` | 프레임 시간 추정에서 최신 프레임의 EMA 가중치(%) |
| \`anomalousFrametimeDetectionCooldown\` | \`10\` | 비정상적으로 긴 프레임을 무시한 뒤 필터가 쉬는 프레임 수 |
| \`enableVrrCursorRelease\` | \`1\` | VRR 유휴 중 커서 전용 갱신 타이머 |
| \`minVrrCursorFPS\` | \`30\` | 커서 전용 갱신 빈도. 0은 갱신 안 함 |
| \`vrrCursorMarginUs\` | \`1500\` | 커서 갱신과 다음 게임 프레임 사이의 보호 시간 |
| \`vrrSmartDetection\` | \`0\` | 슬라이드쇼/엔트로피/헤드 마스크 감지 비트 |
| \`VRRAlwaysOn\` | \`0\` | 앱 요청이 없어도 VRR을 계속 활성화 |
| \`forceVrrTearingMode\` | \`0\` | 0=앱 설정 따름, 1=티어링 허용, 2=티어링 금지 |
| \`enableAdaptiveSync\` | \`0x17\` | DisplayPort Adaptive-Sync 및 HDMI VRR 감지 비트 |
| \`disableOSVRR\` | \`0\` | Windows OS VRR 기능 노출 제어. NVIDIA G-SYNC 경로와 별개 |
| \`vrrMaxRRx1k\` | \`0\` | VRR 최대 주사율 제한(mHz). 0은 제한 없음 |
| \`vrrVblankExtension\` | \`0x3FFF\` | 모니터 최저 주사율을 알 수 없을 때 사용하는 추가 블랭킹 라인 |

## 스마트 감지

스마트 감지는 기본적으로 꺼져 있습니다. 슬라이드쇼 감지는 매우 긴 프레임을 감지하고, 엔트로피 감지는 프레임 시간의 불규칙성을 점수화합니다. 원본 분석에 따르면 실제 표시 효과에는 헤드 마스크 비트가 필요합니다. 이 기능은 실험적이므로 기본값을 유지하는 것이 안전합니다.
